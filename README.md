# НейроСтат

Android-приложение для регистрации и анализа физиологических показателей. НейроСтат подключается к нейроинтерфейсам по Bluetooth, проводит калибровку и тесты, сохраняет измерения локально и синхронизирует их с сервером.

## Возможности

- подключение устройств Neiry и NeuroPlay;
- проверка качества контакта датчиков и заряда устройства;
- запись EEG, MEMS, кардио- и других объективных метрик;
- калибровка и субъективные тесты;
- расчёт показателей утомления;
- история сессий и визуализация результатов;
- ручная и фоновая отправка накопленных данных;
- экспорт локальной базы данных.

## Технологии

- Kotlin и Coroutines;
- Jetpack Compose и Material 3;
- Room;
- Hilt;
- Retrofit, OkHttp и Kotlin Serialization;
- WorkManager;
- Android Bluetooth LE;
- нативный код через Android NDK/CMake.

## Требования

- Android Studio с поддержкой AGP 8.13;
- JDK 17;
- Android SDK 35;
- устройство или эмулятор с Android 8.0 (API 26) и выше;
- для работы с нейроинтерфейсом — Android-устройство с Bluetooth LE.

Сборка приложения выполняется только для архитектуры `arm64-v8a`. Необходимые проприетарные AAR-библиотеки находятся в `app/libs` и отслеживаются в репозитории.

## Запуск

1. Клонируйте репозиторий.
2. Откройте проект в Android Studio и дождитесь синхронизации Gradle.
3. Убедитесь, что Android SDK настроен в локальном `local.properties`.
4. Подключите устройство с Android 8.0+ или запустите подходящий эмулятор.
5. Соберите и запустите конфигурацию `app`.

Сборка из командной строки:

```powershell
.\gradlew.bat assembleDebug
```

После первого запуска приложению необходимо предоставить разрешения Bluetooth и уведомлений. На Android 11 и ниже для поиска Bluetooth-устройств также может потребоваться доступ к геопозиции.

## Проверка проекта

Компиляция Kotlin:

```powershell
.\gradlew.bat :app:compileDebugKotlin
```

Модульные тесты:

```powershell
.\gradlew.bat :app:testDebugUnitTest
```

Инструментальные тесты на подключённом устройстве или эмуляторе:

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

Документация Dokka:

```powershell
.\gradlew.bat :app:dokkaModule
```

## Структура проекта

```text
app/src/main/java/com/neuroproject/neuro/
├── data/          # Room, сеть, устройства и фоновая синхронизация

├── presentation/  # экраны и ViewModel
├── di/            # Hilt-модули
└── components/    # переиспользуемые Compose-компоненты
```
